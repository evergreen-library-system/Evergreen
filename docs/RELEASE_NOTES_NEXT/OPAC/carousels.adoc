== Carousel Access via Iframe ==

The earlier method of embedding carousels in iframes for use on other web sites which broke
in Evergreen 3.16 has been restructured and improved so that a specific carousel may be
selected for display rather than showing all carousels associated with the selected location.

If you wish to embed a carousel in another web site, you can do so using an iframe and the
'/eg/opac/carousel' URL path with specified parameters:

* carousel_loc - (required) the id of the org unit that the carousel(s) is associated with 
* carousel_id - (optional) the id of a specific carousel at the carousel_loc, if none
is specified, all carousels for that location will display
* nofooter=nofooter - (recommended) hides the page footer

Example:

----
<iframe src="https://<mydomain>/eg/opac/carousel?carousel_loc=3&carousel_id=4&nofooter=nofooter"
title="Carousel" width="100%" height="300" frameborder="0" scrolling="no"></iframe>
----
