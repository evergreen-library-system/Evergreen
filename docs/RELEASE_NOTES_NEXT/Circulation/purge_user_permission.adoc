== PURGE_USER Permission ==

A new permission, `PURGE_USER`, is added to give finer control over
who can purge users, i.e. delete and overwrite the patron information,
versus delete users, i.e. set the user's `deleted` field to a true
value.  The new permission allows deleting and overwriting the user's
information.  The current `DELETE_USER` permission allows setting of
the deleted field when a user is deleted.

The previous permission schema used `DELETE_USER` for both.

=== Upgrade Notes ===

The database upgrade adds the `PURGE_USER` permission to any permission
group that currently has the `DELETE_USER` permission.  If you wish to avoid
this, modify the upgrade script.
